Отчёт по домашнему заданию № 3: Реализация строкового калькулятора математических выражений в консольном приложении на языке C++.

Цель работы

Целью данной работы является разработка консольной программы калькулятора, предназначенной для вычисления математических выражений, заданных в виде строки. Программа должна поддерживать основные арифметические операции (+, -, *, /), скобки для задания приоритета вычислений, математические функции (sin, cos, tg, ctg, exp), а также работу с переменной x, значение которой вводится пользователем. Также требуется реализовать проверку корректности введённого выражения и обработку ошибок ввода.



Вычисление результата

После преобразования выражения программа выполняет его вычисление. Если в выражении присутствует переменная x, пользователю предлагается ввести её значение, после чего производится окончательный расчёт.

Контрольный расчёт

Пример входных данных:

cos(x-5)*10/(2*x-5)


При вводе значения:

x = 5


Результат вычисления:

2

Итог

Результат совпадает с ожидаемым, что подтверждает корректность работы программы.
